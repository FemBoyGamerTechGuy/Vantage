# GTK Integration

Vantage themes GTK3 and GTK4 applications without requiring GTK as a
dependency of the desktop core.

## Mechanism

When `vantage-theme apply` is run (or at session startup), Vantage:

1. Reads the active theme JSON file.
2. Generates `~/.config/gtk-3.0/gtk.css` with `@define-color` directives
   and basic widget styles.
3. Generates `~/.config/gtk-4.0/gtk.css` (same syntax, GTK4-compatible).
4. Sets `GTK_THEME=vantage` so apps use the generated CSS as a base.
5. Sets `GTK_APPLICATION_PREFER_DARK=1` for dark themes.
6. Sets `GTK_ICON_THEME=<configured icon theme>`.

GTK3 and GTK4 applications read these files automatically at startup
— no plugin or shared library needed.

## Generated CSS example

For `Vantage-Dark`, the generated `gtk.css` looks like:

```css
/* Generated by Vantage theme engine. Do not edit. */
@define-color accent #3b82f6;
@define-color bg #1e1e2e;
@define-color fg #cdd6f4;
@define-color surface #313244;
@define-color border #45475a;

* { font-family: Sans; font-size: 11pt; }

window { background-color: @bg; color: @fg; }
button { background-color: @surface; color: @fg;
         border-radius: 8px; border: 1px solid @border; }
button:hover { background-color: @accent; color: white; }
```

## Updating themes live

When you change the theme via `vantage-theme apply`, GTK apps that
are already running won't pick up the new CSS automatically. You can
either:

* Restart the GTK apps.
* Use `gsettings set org.gnome.desktop.interface gtk-theme Vantage`
  to force a reload (the GTK_THEME env must match).

## Icon themes

To install additional icon themes:

```sh
# Per-user:
mkdir -p ~/.local/share/icons
# drop icon theme directory here
# then:
vantage-config set desktop icon-theme "MyIcons"
```
